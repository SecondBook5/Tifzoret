# Minimal synthetic demo

This template contains a runnable synthetic dataset demonstrating the engine's core workflow. The study compares three conditions (control, treatment_a, treatment_b) across nine samples (three replicates each), with two contrasts against control, pre-validated integer counts, annotation, and a minimal gene-set GMT. Run `tifzoret run project.yaml --cores 2` to execute the standard-profile analysis, producing canonical inputs, QC figures, differential-expression results, pathway enrichment, and an HTML report under `results/synthetic_demo/all/`. This is a proof-of-execution scaffold — real studies require domain-appropriate inputs, design formulas, and hypothesis-driven configurations.
